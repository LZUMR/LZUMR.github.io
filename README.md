## 项目介绍

LZU Math Resources 是一个面向兰州大学数学与统计学院、萃英学院数学相关课程的资料导航项目，旨在整理课程笔记、作业参考、历年试卷、考试回忆、代码与建模材料等资源。

项目已构建为一个可部署到 GitHub Pages 的静态网站。网站支持按科目浏览资料、展开文件列表、打开或下载文件，并可通过顶部搜索框检索科目名称、科目描述和文件名。

## 参与建设

欢迎大家一起参与数学资料库的长期建设。你可以补充课程资料、修正文档说明、规范文件命名、整理重复资源、完善科目分类，或帮助改进网页体验。

目前尤其希望一起推进这些工作：

- 补充更多课程的历年试卷、回忆版、讲义、笔记和代码。
- 统一文件命名规范，例如课程名、年份、学期、考试类型、教师或班级信息。
- 合并内容相同但位于不同文件夹的重复资源。
- 为资料添加更清晰的来源说明和适用范围。
- 发现侵权、隐私或不适合公开的内容时及时联系维护者处理。

如希望贡献资料、参与整理，或对命名规范化有建议，可以联系我。

## 🛠️更新资源索引

新增、移动或整理资源文件后，需要重新生成网站使用的静态目录数据：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-catalog.ps1
```

该脚本会扫描项目中的资源文件夹，并更新 `catalog.js`。随后刷新网页即可看到最新资源列表。
